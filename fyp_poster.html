Introduction

The growth of the modest fashion industry has led to an increase in online hijab shopping platforms. However, product data remains fragmented across different brand websites and online marketplaces, each using inconsistent formats and data structures. This project proposes a centralized hijab catalogue web application that aggregates product data from multiple brands into a unified platform, enabling users to browse, search, filter, and purchase hijab products across brands without barriers. The application features a colour-based search and recommendation system using HSL colour family matching to help users find visually similar products.

Problem Statement
  • Hijab product data is fragmented across different brands with inconsistent formats
  • Limited filtering criteria (colour, size, fabric) in existing platforms
  • No quick-access tool to revisit previously viewed products
  • Minimal cross-brand product recommendations
Objectives
1

Develop a normalized data model for consistent product attributes

2

Implement faceted filtering with colour, size, material, and brand criteria

3

Build a Favourites feature for quick product access

4

Develop a colour-based recommendation using HSL matching
